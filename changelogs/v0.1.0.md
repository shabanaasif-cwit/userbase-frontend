# v0.1.0 — 2026-03-19

(D) 2026-03-19

### Added

- Admin page(s) at `/admin/notifications` to create, update, and delete notifications.
- UI to target notifications by “all”, “by role”, or “specific users” (mock data / localStorage until backend API exists).
- Notification list in admin panel with edit/delete actions.
- Notifications store (`app/lib/notifications-store.ts`) for frontend-only persistence.
- Notifications display on the dashboard and as an alert banner.
- Header with notification list/dropdown.
- User notifications page at `/notifications`; mark as read in the UI (backend call ready when API exists).
- Auth: `ManagedUser` type, `getManagedUsers()`, `setUserStatus()`, `updateUserRole()`, `USER_STATUS_KEY`; login blocks deactivated users.
- Edit user (role and account status) and Deactivate/Activate actions; state in `localStorage`.
- Admin dashboard cards linking to `/admin/users` and `/admin/notifications`.
- Next.js optimizations: ISR on home, about, terms, privacy, gallery; server components with small client boundaries (WelcomeCTA, ContactForm); PageShell for content pages; metadata for SEO.
- Reusable `PageShell` component (variant light/dark, maxWidth narrow/default/wide).
- Global CSS for native `select`/`option` so dropdown options are visible.
- Gallery: `GalleryGrid` client component with "View all" / "Show less", curated Unsplash images (user-management themes), image error fallback and `object-contain`; `next.config` remote patterns for Unsplash.
- Dev-only Cache-Control headers in `next.config.ts` to allow bfcache in development (production unchanged).

### Changed

- Updated UI components for the notification section for better usability.
- Improved notification management interface for a more user-friendly approach.
- Notifications are interactive; users can open detailed views via modals.
- Admin Notifications create module: fixed height with scroll so the list does not expand as it grows.
- Integrated SSR, SSG, and ISR optimizations where applicable on Next.js pages.
- About page: accent colors (sky, emerald, amber), gradient bars, icons (Target, Layers, Shield, Users), card hover and shadows.
- Contact page: hero and contact-method cards with sky/emerald/amber accents, icons (Mail, Phone, MapPin); ContactForm styling (sky submit button, emerald/red messages).
- Gallery page: uses `GalleryGrid` with responsive grid (md:2, lg:3 columns); images from Unsplash.
- Admin dashboard: bento-style cards with icons (Bell, Users), gradient orbs, "Signed in as" pill; responsive padding.
- Admin users: hero with Users icon and emerald/sky accents; table and Edit dialog with emerald accents; search/filters and pagination styling.
- Admin notifications: hero with Bell icon and sky accents; table and Create/Edit/Delete dialogs with sky/red accents; form focus rings and target-option styling.
- User notifications page: hero with Bell icon, unread pill, "Mark all read"; list read/unread states, relative time, empty state and detail modal styling.
- Dashboard: hero gradient orbs, responsive padding; activity table and notification cards layout.
- Home page: responsive padding (px-4, sm:px-6).
- PageShell: responsive padding (px-4 py-10, sm:px-6 sm:py-16).
- Header: notification dropdown `max-w-[calc(100vw-2rem)]` so it does not overflow on small viewports.
- Responsiveness: admin users and admin notifications tables in `overflow-x-auto` with min-width; search/filters full-width on mobile; admin notifications card header stacks on small screens; dashboard activity table scrollable; profile and main pages use responsive padding.

### Fixed

- “Mark as read” now updates the unread badge count immediately after marking a notification.
- Notifications now display correctly on the dashboard.
- Dropdown options in the notification UI are visible without hover.
- Code refactored for clarity and maintainability.
