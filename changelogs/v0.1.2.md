# v0.1.2 — 2026-03-30

(D) 2026-03-30

### Added

- Centralized browser tab titles: `document.title` is set from the current route in the main header via a path-to-title map, so each main area gets a consistent title suffix (for example profile, dashboard, notifications, auth, admin, and static pages).

### Changed

- Terms of use page: the “effective as of” date is derived at render time from the server locale instead of a hardcoded string, and the page uses a one-day revalidation window so the displayed date stays current without manual edits.
- Notifications listing page: hero layout tightened (spacing and typography) so the top section reads more clearly on small and large screens.
