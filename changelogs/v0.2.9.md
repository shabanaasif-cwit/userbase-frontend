# v0.2.9 - 2026-04-17

(D) 2026-04-17

### Added

    - Full-screen `Maintenance` experience when the backend cannot be reached.
    - `isApiReachable()` in `app/lib/api-config.ts`: probes `GET ${API_BASE}/api/auth/me` with an 8s abort timeout and `cache: "no-store"`; any successful HTTP response counts as reachable.

### Changed

- `app/layout.tsx` is now an async server layout: when the API is reachable, it renders `AuthProvider` and `AppShell` as before; otherwise it renders only `Maintenance` (no auth shell or child routes UI).
- `app/page.tsx`: home route is `export const dynamic = "force-dynamic"` instead of hourly ISR (`revalidate = 3600`).

### Fixed

- Avoids loading the authenticated app shell against a dead API, replacing it with a dedicated maintenance message until connectivity returns.

### Internal

- Centralized API base resolution unchanged; reachability helper lives next to `readJsonSafe` / `authHeaders` in `api-config`.
- `WelcomeCTA` import on the home page updated to `@/app/component/welcome-cta`.
