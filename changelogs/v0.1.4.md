# v0.1.4 - 2026-04-03

(D) 2026-04-03

### Added

- New authenticated reminders page at `app/reminders/page.tsx` with unread counts, empty state, relative timestamps, and actions to mark individual reminders or all reminders as read.
- Reminder navigation entry points in the header for desktop and mobile, plus a quick reminder link inside the notifications menu.
- Direct link from the notifications page to the new reminders screen.

### Changed

- `app/lib/notifications-api.ts` now supports reminder payloads returned under `reminders` and maps them into a typed `ReminderItem` model.
- Reminder fetching now normalizes API rows and sorts reminders by newest `createdAt` first before rendering.

### Fixed

- Reminder data returned from the API can now be displayed reliably even when the backend uses reminder-specific response keys instead of notification keys.
- Header notification actions now wrap more cleanly on smaller widths by allowing the action row to flex and wrap.

### Security (if applicable)

- No security-specific changes in this release.

### Internal

- Added reminder-specific typing and mapping helpers in `app/lib/notifications-api.ts` to keep the UI aligned with backend reminder responses.
