# v0.3.4
(D) 2026-04-27

### Added
- Added a `Created By` column before `Created At` on the admin notifications page.
- Added reminder creator metadata support so reminder items can read the sender/creator value from the API response.
- Added `Created by` display support for reminders on the admin side.

### Changed
- Updated notification creator mapping to support nested `createdBy` objects and prefer `createdBy.email` with fallback to `createdBy.userId`.

### Fixed
- Fixed admin notifications so `Created By` reads from backend `createdBy.userId` when the creator is returned as an object.
- Fixed reminders to hide `Created by` from regular users while still allowing it for admins.

### Security (if applicable)
- No security changes in this release.

### Internal
- Extended shared notification/reminder frontend typings to carry creator metadata without changing existing notification or reminder flows.
