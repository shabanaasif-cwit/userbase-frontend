# v0.3.2 - 2026-04-22

(D) 2026-04-22

### Added
- **`app/admin/dashboard/page.tsx`:** Linked the signed-in user email in the admin dashboard hero pill to the profile page at `/profile`.
- **`app/lib/auth-context.tsx`:** Added persisted auth session support with `userbase:auth-session` storage so user and token data can be restored on reload before `/api/auth/me` finishes.
- **`app/signup/page.tsx`:** Added inline first-name and last-name validation errors when users enter unsupported characters during signup.

### Changed
- **`app/admin/dashboard/page.tsx`:** Added interactive link styling to `user.email`, including `cursor-pointer` and a hover color transition.
- **`app/component/footer.tsx`:** Replaced footer anchor tags with Next.js `Link` components for internal navigation links.
- **`app/component/header.tsx`:** Increased the notification and reminder badge overflow cap from `9+` to `99+`.
- **`app/component/header.tsx`:** Updated the desktop notifications trigger to use the shared navigation link styling for more consistent header behavior.
- **`app/gallery/gallery-grid.tsx`:** Simplified gallery cards by removing the extra "Explore" call-to-action button and trimming redundant button cursor styling on the show-more control.
- **`app/lib/auth-context.tsx`:** Expanded auth session parsing to support more nested `/api/auth/me` response shapes and recover access tokens from multiple payload locations.
- **`app/lib/auth-context.tsx`:** Startup auth hydration now prefers any stored session while revalidating with the server, reducing unnecessary client-side session resets when the API response is delayed or wrapped differently.

### Fixed
- **`app/admin/dashboard/page.tsx`:** Signed-in users can now click their email address to navigate directly to their profile page.
- **`app/signup/page.tsx`:** Prevented first and last names containing numbers or special characters from being submitted, with field-level feedback shown immediately.
- **`app/lib/auth-context.tsx`:** Logout now clears the persisted auth session in addition to in-memory auth state.
