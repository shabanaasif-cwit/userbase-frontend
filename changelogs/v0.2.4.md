# v0.2.4 - 2026-04-10

(D) 2026-04-10

### Added
- Added reminder model support for `isRecipient` and `myRead` fields in the frontend reminder API mapping so the UI can distinguish recipient-specific visibility and read state metadata returned by the backend.

### Changed
- Updated the reminders page unread-count logic to count only reminders where the current viewer is a recipient.

### Fixed
- Fixed the reminders page so the `Mark read` action is hidden for reminders that do not belong to the current recipient.
- Fixed reminder badges derived from `reminderUnreadCount` so non-recipient reminders no longer contribute to the unread alert shown from reminders page state.

### Security (if applicable)
- Not applicable for this release.

### Internal
- Extended `ReminderItem` typing and response normalization in `app/lib/notifications-api.ts` to preserve backend reminder metadata without changing unrelated notification flows.
