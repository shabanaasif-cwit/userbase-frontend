# v0.1.5 - 2026-04-03

(D) 2026-04-03

### Added

- No new user-facing features in this release.

### Changed

- Role-targeted notifications using `targetType: "role"` are now reflected correctly in those unread-only views after their read state changes.
- Unread notification surfaces now consistently render only unread items across the notifications page, header dropdown, profile activity panel, and dashboard notification card.

### Fixed

- Opening a notification now removes it from unread visibility immediately after it is marked as read.
- "Mark all read" actions now clear unread notification lists instead of leaving read items visible in unread-only views.

### Security (if applicable)

- No security-specific changes in this release.

### Internal

- Consolidated unread notification filtering in the affected UI surfaces to keep badge counts and rendered lists aligned with the read state.
