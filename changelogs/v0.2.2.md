# v0.2.1 — 2026-04-08

(D) 2026-04-08

### Added
- Profile display: Incorporated firstName and lastName for the user profile, enabling the display of the full name rather than relying on the fallback email-based name.
- getInitials logic update: Enhanced the getInitials function to correctly derive initials by using the just first letter of firstName. 
- Added Label field in the contact form for a more intuitive form structure

### Changed
- Profile name construction: Refined the logic to ensure the profile name now properly prioritizes firstName and lastName fields, offering more user-friendly name handling on the frontend.
- Display name fallback: If firstName and lastName are unavailable, the system now defaults to a fallback method that uses the local part of the email, ensuring a smooth user experience across various scenarios.
- Initials rendering: The getInitials function now ensures two initials are rendered based on both firstName and lastName, offering better clarity in user interfaces such as profile icons and avatars.
