# v0.3.1 - 2026-04-21

(D) 2026-04-21

### Added
- **`app/lib/auth-context.tsx`:** Added `passwordMaxLength` to the shared auth validation config for signup password-length checks.

### Changed
- **`app/signup/page.tsx`:** Signup password validation now enforces the configured minimum and maximum length values from `authValidation` instead of using a hardcoded minimum only.
- **`app/signup/page.tsx`:** Added a dedicated password-length error message for values shorter than 8 characters or longer than 64 characters while keeping the existing invalid-character and number/special-character messages unchanged.

### Fixed
- **`app/signup/page.tsx`:** Signup now blocks submission and shows a relevant inline error when the password length falls outside the allowed 8-64 character range.

### Security (if applicable)
- **`app/signup/page.tsx`:** Prevented out-of-range password values from being submitted during signup by enforcing the defined client-side length boundaries.

### Internal
- **`app/lib/auth-context.tsx`:** Normalized the file ending with a trailing newline while extending the shared auth validation constants.
