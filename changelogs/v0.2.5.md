# v0.2.5 - 2026-04-10

(D) 2026-04-10

### Added
- Added session-based reminder read tracking keyed by the logged-in user so reminders can stay visually read during the current login session without changing unrelated notification behavior.

### Changed
- Updated the reminders page to treat reminders marked read in the current session as read for card styling, `Mark read` button visibility, and unread-count calculations.
- Updated the header reminder badge to recalculate unread reminders from the reminders API and exclude reminders already marked read in the current session.
- Changed the notification dropdown `View all` action to navigate to `/notifications` for all roles.

### Fixed
- Fixed reminder cards so once a reminder is marked read, its unread styling is removed immediately and the `Mark read` action stays hidden for the rest of that login session.
- Fixed reminder alert counts so they stay aligned with session-marked reads instead of reappearing during in-session navigation.
- Fixed logout behavior by clearing temporary reminder read session state, allowing unread reminders to appear again on the next login unless they were actually marked read on the backend.

### Security (if applicable)
- Not applicable for this release.

### Internal
- Added `app/lib/reminder-read-session.ts` to isolate sessionStorage read/write/clear helpers for reminder read state.
- Connected logout cleanup in `app/lib/auth-context.tsx` to the reminder session helper so temporary client-only state is removed when a user signs out.
