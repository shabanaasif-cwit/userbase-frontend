# v0.1.0 — 2025-03-17

(D) 2025-03-17

### Added

- Admin user management page at `/admin/users`: ShadCN data table with username, email, role, and account status.
- Search by name/email, filters by role and status, and pagination (rows per page: 5, 10, 25, 50).
- Edit user (role and account status) and Deactivate/Activate actions; state persisted in `localStorage` (frontend-only).
- Auth: `ManagedUser` type, `getManagedUsers()`, `setUserStatus()`, `updateUserRole()`, and `USER_STATUS_KEY` for per-user status (active/deactivated).
- Login now blocks deactivated users from signing in.
- Global CSS for native `select`/`option` so dropdown options are visible (theme-based background and text color).
- Branch `admin-usermanagement` for user management work; branch `admin-notifications` for notifications work.

### Changed

- Admin dashboard card "User management" now links to `/admin/users` (Go to User management →) instead of placeholder text.
- Dashboard page modernized: personalized "Hello, {name}" hero, quick action cards (Profile, Gallery, Support), single status banner, simplified notifications section.
- `getUserStatusMap()` in auth-context: return type and parsing updated so TypeScript accepts `Record<string, "active" | "deactivated">`.

### Fixed

- Type error in `app/lib/auth-context.tsx`: `getUserStatusMap()` return type incompatible with `Record<string, string>`; fixed with proper cast to `Record<string, "active" | "deactivated">`.
- Dropdown options not visible until hover; addressed with solid select backgrounds and `select option` styling in `globals.css`.
