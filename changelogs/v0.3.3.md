- **`app/admin/dashboard/page.tsx`:** Added a prominent "Back to Dashboard" pill-style link at the top of the admin dashboard hero.

- **`app/reminders/page.tsx`:** Fixed unread reminder totals so they stay accurate across paginated reminder data and sync correctly with the header badge.
- **`app/component/header.tsx`:** Fixed reminder badge updates so count changes from the reminders page are reflected more reliably in both desktop and mobile navigation.
